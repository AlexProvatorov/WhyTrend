# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.4.x   | Yes       |
| < 0.4   | No        |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Instead, report privately:

1. Prefer [GitHub Security Advisories](https://github.com/AlexProvatorov/WhyTrend/security/advisories/new) for this repository, **or**
2. Email: `sasha.provatorov@gmail.com`

Include:

- Affected version / commit
- Description of the issue and impact
- Steps to reproduce (PoC if possible)
- Any suggested fix

You should receive an acknowledgement within **7 days**. After triage we will outline next steps (fix timeline, advisory, CVE if applicable).

Please give us reasonable time to ship a fix before any public disclosure.
